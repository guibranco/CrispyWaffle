Version 10.4 [2026-10-16]

Version 10.3 [2026-10-16]

  • Add YAML serializer support using YamlDotNet - issue #432 and pull request #980 by @rodri-oliveira-dev
  • Rewrite the documentation site, with a page for every core module and integration package plus architecture diagrams - pull request #1007 and pull request #1008

Version 10.1 [2026-07-04]

  • Fix the inverted logic in ExtractQuerystring - pull request #881 by @Sak3th2004
  • Replace XXXX placeholders in XML documentation with real return descriptions - pull request #882 by @Sak3th2004
